AL-MUSLIM v105 — ما تغيّر
1) المساجد: GPS عالي الدقة، تحذير عند ضعف الدقة، حذف المهجور/غير الإسلامي، دمج المكرر، زر خرائط Google.
2) القراء المثبّتون (archive.org): جلب اسم الملف الحقيقي + تحميل مسبق + بديل Blob عند فشل Safari.
3) تكرار الآية: بلا نهاية حتى «إيقاف»؛ تكرار كل آية N مرات يعمل (حتى بالبديل)؛ فجوة اختيارية (بقدر طول الآية)؛ عرض «المرة x من N».
4) الأوضاع: 7 أوضاع جديدة + ابنِ وضعك + إعادة بلا توقف + آخر وضع + الصوت والفجوة + مؤقت 5/120.
5) الأحاديث: مؤجّلة (غير متاحة) كالمصحف والتسميع.
6) الأذكار والرقية: زر التحميل يختفي بعد التحميل ويبقى كذلك بعد إعادة فتح الموقع.
7) مساعد المسلم: محادثة + فهم السورة/الآيات/القارئ + اعتذار مع ذكر المصدر. (النموذج الذكي الكامل اختياري: supabase/functions/muslim-assistant)
8) إصلاح خطأ قديم عند التحميل (D65 is not defined).
